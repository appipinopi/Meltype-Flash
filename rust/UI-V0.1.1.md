# v0.1.1 向け Windows UI 調整

ユーザー提供の設定画面・トレイメニュー画像を基準に、Rust 設定アプリを調整。
上流の C# 実装は参照用のまま変更しない。

- 設定の初期サイズを 720 × 700 論理ピクセル（タイトルバーを除く）へ変更。
- Windows の Yu Gothic UI を TTC の正しいフェイスから読み込み、明色の配色を固定。
- 独自ヘッダー・常設タブ・検索を初期画面から除き、プロファイルと表示オプションを上部へ配置。
- 全般の項目順・分類枠・行間・40 × 20 のスイッチ・250 幅の選択欄を参照画像に合わせる。
- 下部は固定高の説明、判定テスト、右寄せの既定値・OK・キャンセル。
- トレイは参照画像と同じ項目順・区切り・バックアップ／学習削除／更新サブメニューを用意。
- 判定の強さ・プロファイル・自動更新の現在値をトレイに反映。
- 学習削除は範囲を選んで確認後に実行。「今日」は実行環境のローカル日付の午前0時以降。
- 単独で設定アプリを開いた場合、背景の右クリックから他の画面・検索・全設定へ移動できる。
- 保存・キャンセル・開いている間のトレイ変更とのマージは既存処理を維持。

## 検証

`cargo test -p meltype-settings --features visual-test --locked`

`tools/parity/ui/capture_settings.py` で通常データから分離した6画面をキャプチャ。
`tools/parity/ui/evidence/windows-v011-layout/report.json` に実行ファイルのハッシュと結果を保存。
撮影中に設定ファイルを書き換えず、ユーザー辞書を移行しないことをスクリプトで検査。
これは描画の確認であり、画素単位の一致や実機での全メニュー操作の合格を意味しない。

## 残る差

描画は egui、本家は WinForms のため、文字のラスタライズ・スクロールバー・メニューの描画は異なる。
全般の未移植項目は設定値の保存に対応し、ホバー時の下部説明に制限を示す。
「ログ / 判定理由」はFlash保存先の tip.log を読み、最大256KiBの末尾を500ms間隔で表示。判定／IME切替の絞り込みとコピーに対応。記録のない状態では空欄を表示する。
「直した誤判定を報告」は専用画面を開く。入力テストの訂正を終了まで最大64件保持し、キー・表示・期待値・前後文を編集してコピー／GitHubの各フォーム項目へ渡せる。IME全体の訂正履歴の収集は未接続。
バックアップの両項目は保存／読込ダイアログを直接開き、復元は内容確認と確認画面の「戻す」の後に実行する。
アンインストールは専用画面に配布済みの管理コマンドを表示する。
版番号の更新・リリース公開・既存 IME の入れ替えはこの変更に含めない。

## Meltype-FLASH の専用画面（追加）

報告・誤判定の報告・ログ・About・更新をOSの独立ウィンドウに分けた。
「不具合の報告・提案」は実行環境と編集可能なログを表示する。ログはURLに入れず、明示的なコピー操作で渡す。
GitHubへの内容の送信は実行せず、ユーザー操作で入力済みの報告画面を開く。
Aboutには製品名・版・ライセンスを表示し、更新操作は別の更新画面に置く。
Space／Enter長押しの自動リピートでスイッチが繰り返し切り替わる問題も修正。

検証:

- 設定アプリ29試験成功、対話用1試験未実行。
- `check_dialog_windows.py` は私用データで5つの実OSウィンドウを開き、個別のWM_CLOSEで設定ウィンドウが残ることを確認。
- 設定ファイルが不変、辞書移行なし、IME登録なしを検査。
- `tools/parity/ui/evidence/flash-dialogs-v011/` にネイティブウィンドウの検査結果と同じ本文を埋め込んだ描画キャプチャを保存。
- 誤判定キャプチャの「hashi／橋／箸」は表示検査用の合成データ。

WinFormsのネイティブ部品との画素単位の一致、IME全体の診断・訂正履歴、アンインストール実行画面は引き続き未完了。
