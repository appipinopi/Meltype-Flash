# Meltype-FLASH v1.1.2

This release uses the shared Rust Core on Windows, macOS, Linux, Android, ChromeOS, and iOS. It does not mean that every environment has the same features or the same accuracy.

## What's new

- **Added a first-start consent screen.** It explains the license (GNU GPL v3 or later, no warranty) and how usage data is handled. You cannot start using the settings until you agree.
- **Usage analytics (Aptabase) can no longer be turned off.** It sends only the app version, OS version, launch count, and the number of screens opened. It never sends typed text, input history, dictionaries, settings, or the contents of input fields. The on/off switches were removed from the Windows, macOS, iOS, and Android settings and input menus. Linux and ChromeOS do not send usage analytics.
- Added a category list on the left side of the settings window, so you can show only the selected category.
- **Usage analytics (Aptabase) now also runs on Linux and ChromeOS.** Linux sends from the settings window; ChromeOS sends after agreeing in the first settings screen.
- **Keystroke counts and Discord Rich Presence now work on all desktop builds: Windows, macOS, and Linux.** ChromeOS, Android, and iOS are out of scope.
- **Added a CRX-free update path for ChromeOS.** Choose "Update from ZIP (no CRX)" in the settings, select the extension folder, and the release ZIP is verified with SHA-256 before it is written.
- **Added guidance for `CRX_REQUIRED_PROOF_MISSING` on the ChromeOS build.** Install the ZIP with "Load unpacked" in normal use. The CRX is for managed-policy installation (`ExtensionInstallForcelist`); dragging it into Chrome does not work.
- Registered "Meltype-FLASH" in the Windows Start menu and the Win-key app list. You can launch it from Windows 11 search.
- The settings window can now be shown in English. Choose "Auto / Japanese / English" in the settings language option.
- Added seasonal candidates (Christmas, Halloween, Valentine's Day, and New Year). They appear only during their seasons.
- Added an option to start conversion with the last clause selected when you begin conversion with Space or Tab.
- The ChromeOS build supports automatic updates through the signed CRX and `updates.xml`. If you loaded the ZIP manually, use "Check for updates" in the settings to find a new version.

## Notes for updating

- After you agree, usage analytics cannot be turned off. If you do not agree, please quit the app.
- The ChromeOS build is not an IME for desktop Chrome. Use it on ChromeOS where `chrome.input.ime` is available.
- Installing the iOS build on a device requires signing. AI models are downloaded separately from the app.
