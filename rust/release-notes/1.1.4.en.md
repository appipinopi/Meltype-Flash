# Meltype-FLASH v1.1.4

This is a fix release for v1.1.3. It uses the shared Rust Core on Windows, macOS, Linux, Android, ChromeOS, and iOS.

## What's new

- **Fixed the settings window layout.** The left category column now has a fixed width, and the settings on the right no longer collapse or overflow at the window edge. The category list scrolls vertically, and the app-specific settings editor scrolls horizontally.
- **"とけい" and "じこく" now offer the current time in the configured time zone.** Set the Time zone option to `Asia/Tokyo`, `UTC`, `America/New_York`, and so on. The default is `Asia/Tokyo`.
- **Added an option to include pre-releases in automatic updates.** It is off by default, so the existing stable-only behavior is unchanged.
- **Keystroke counting is now off by default.** It counts only when "Count keystrokes" is enabled in the settings, matching the upstream default.
- **Added Linux and macOS documentation.** See `docs/LINUX.md` and `docs/MACOS.md` for installation, settings, and updates.
- Apps that were running before an update should be restarted once to load the new IME or input method.

## Notes for updating

- The first-start consent and usage analytics added in v1.1.3 are unchanged. After you agree, analytics cannot be turned off.
- The ChromeOS build is not an IME for desktop Chrome. Use it on ChromeOS where `chrome.input.ime` is available.
- Installing the iOS build on a device requires signing. AI models are downloaded separately from the app.
