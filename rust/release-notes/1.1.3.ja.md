# Meltype-FLASH v1.1.3

Windows・macOS・Linux・Android・ChromeOS・iOS で共通の Rust Core を使う版です。すべての環境で同じ機能・精度という意味ではありません。

## 今回の変更

- **はじめる前の同意画面を追加しました。** ライセンス（GNU GPL v3 以降・無保証）と利用状況の扱いを表示し、同意するまで設定画面を使い始められません。
- **利用状況（Aptabase）をLinuxとChromeOSにも接続しました。** Windows・macOS・iOS・Androidに加え、Linuxは設定画面から、ChromeOSは初回の設定画面で同意したあとに送ります。送るのはアプリの版・OSの版・起動回数・画面を開いた回数だけで、入力内容・入力履歴・辞書・設定値・入力欄の文字列は送りません。同意後の送信は停止できません。
- **設定画面の左側に分類一覧を追加しました。** 全般・入力モード・判定・変換・候補・記号・スペース・キー操作・表示・学習・アプリ・ログ・更新から選び、その分類だけを表示できます。
- **アプリ内のリリースノート表示を追加しました。** 更新後の初回起動で一度だけ表示し、設定の「更新」、トレイの「更新」→「リリースノート...」、右クリックメニューからいつでも開けます。Markdownを描画し、日本語とEnglishを切り替えられます。
- **打鍵数とDiscordのステータス表示を、Windows・macOS・LinuxのPC版すべてで使えるようにしました。** ChromeOS・Android・iOSは対象外です。
- **ChromeOS版に、CRXを使わない更新を追加しました。** 設定画面の「ZIPで更新（CRXなし）」で拡張機能のフォルダーを選ぶと、配布ZIPをSHA-256で確認して書き込みます。
- **ChromeOS版のCRXで `CRX_REQUIRED_PROOF_MISSING` と表示される場合の案内を追加しました。** 通常はZIPを「パッケージ化されていない拡張機能」として読み込んでください。CRXは管理ポリシー（`ExtensionInstallForcelist`）で導入するためのファイルです。

## 更新時の注意

- 利用状況の送信は、同意後に停止できません。同意しない場合はアプリを終了してください。
- macOS/LinuxのDiscord表示は、設定アプリ `meltype-flash` が起動している間だけ動作します。
- Linux・macOSの実機、Android・iOSの実ビルドは、この版の確認範囲に含まれていないものがあります。
- iOSの実機導入には署名が必要です。AIモデルは本体と別ダウンロードです。
