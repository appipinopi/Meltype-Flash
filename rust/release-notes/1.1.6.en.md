# Meltype-FLASH v1.1.6

This release adds kana input layouts and key-count settings.

## What's new

- **Added kana input layouts.** Choose JIS kana, Tsuki, Hana, NICOLA, middle-finger NICOLA, or TRON in the Kana layout setting. Tsuki and Hana use prefix shift; NICOLA and TRON use thumb shift.
- **Added the SKY romaji layout.** Choose QWERTY or SKY in the Romaji layout setting.
- **Moved keystroke counts into the settings window.** The top-level Keystrokes tab is gone; open it from the Keystrokes category on the left.
- **Added "Show on Discord status" to the Display settings.** Turn Discord presence on or off from the Display category.
- **Added "Show keystrokes in the tray".** When enabled, the tray tooltip shows today's keystroke count.
- **Changed the default Discord text.** The state line is now `合計 {total} 打 · {kpm} 打/分`, without the AI indicator.
- Includes the v1.1.5 now-playing song candidate and the Meltype IME "あ / A" indicator.

## Kana layout limitation

NICOLA, middle-finger NICOLA, and TRON currently support pressing the thumb key before the character key. Pressing the character key before the thumb key requires a key-up API in each OS input layer, which will follow.

## Notes for updating

- Kana layouts apply when Input style is Kana. The Romaji layout applies to romaji input.
- Apps that were running before an update should be restarted once to load the new IME.
