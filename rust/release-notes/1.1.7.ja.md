# Meltype-FLASH v1.1.7

ChromeOSの半角/全角キー、非同期変換、SKK設定、ReadingLatticeの精度を改善した版です。

## 今回の変更

- **ChromeOSの半角/全角キーを修正しました。** keyupのキー名やcodeが変わっても所有状態を解除し、次の半角/全角で日本語へ戻れます。
- **非同期変換を追加しました。** 設定「変換を非同期で行う」をONにすると、Space/変換キーで待たずに戻り、結果到着後に候補表示を更新します。Windows TSF・IBus・macOSに対応します。
- **AIモデルに Gamma・Qwen・Shion を追加しました。** Zenzai と同じ llama-server / GGUF の経路で扱います。モデルカタログにURL・SHA-256・サイズを登録し、設定画面から導入できます。
- **SKKライクな入力を設定画面から選べるようにしました。** 大文字で▽開始、Spaceで▼変換、Enterで確定します。SKK候補は既存の候補ウィンドウへ表示されます。
- **ReadingLatticeの精度を改善しました。** 英語短縮形、日本語の活用形、数字+助数詞（3月・1人・10時など）、メール・URL・ファイル名・パス、ドメイン・バージョン接尾辞、頭字語、ユーザー学習英語・ユーザー辞書の重みを追加しました。
- **ZenzaiのGPU設定を追加しました。** 設定「Zenzai: 使う GPU」でllama-serverの `--device` を指定できます。空ならCPU/既定GPUです。
- `katakana.txt` / `readings-extra.txt` のライセンス表示を追加しました。

## 更新時の注意

- 非同期変換は既定OFFです。ONにした場合、結果到着まで候補表示が遅れることがあります。
- 更新前に起動していたアプリは、更新後に一度再起動すると新しいIMEを読み込みます。
