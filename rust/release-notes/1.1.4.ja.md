# Meltype-FLASH v1.1.4

v1.1.3 の修正版です。Windows・macOS・Linux・Android・ChromeOS・iOS で共通の Rust Core を使います。

## 今回の変更

- **設定画面のレイアウトを修正しました。** 左分類の幅を固定し、右側の設定項目が画面の右端で潰れたり、横にはみ出したりしないようにしました。左分類は縦にスクロールできます。「アプリ」のアプリ別設定は横スクロールできます。
- **「とけい」「じこく」で、設定したタイムゾーンの現在時刻を候補に出すようにしました。** 設定の「タイムゾーン」に `Asia/Tokyo`、`UTC`、`America/New_York` などを指定できます。既定は `Asia/Tokyo` です。
- **プレリリース版も自動更新の対象にする設定を追加しました。** 既定はOFFです。正式版だけを確認するこれまでの動作を保ちます。
- **打鍵数の既定をOFFにしました。** 設定画面で「打鍵を数える」を入れた場合だけ数えます。本家の既定に合わせています。
- **Linux / macOS の文書を追加しました。** `docs/LINUX.md` と `docs/MACOS.md` から、各OSの導入・設定・更新を確認できます。
- 更新前に起動していたアプリは、更新後に一度再起動すると新しいIME・入力メソッドを読み込みます。

## 更新時の注意

- v1.1.3 で追加した初回同意と利用状況の送信は、この版でも同じです。同意後の送信は停止できません。
- ChromeOS 版は通常のデスクトップ Chrome 用 IME ではありません。`chrome.input.ime` が使える ChromeOS で利用してください。
- iOS の実機導入には署名が必要です。AI モデルは本体と別ダウンロードです。
