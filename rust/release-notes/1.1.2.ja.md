# Meltype-FLASH v1.1.2

Windows・macOS・Linux・Android・ChromeOS・iOS で共通の Rust Core を使う版です。すべての環境で同じ機能・精度という意味ではありません。

## 今回の変更

- **はじめる前の同意画面を追加しました。** ライセンス（GNU GPL v3 以降・無保証）と利用状況の扱いを表示し、同意するまで設定画面を使い始められません。
- **利用状況（Aptabase）の送信を停止できないようにしました。** 送るのはアプリの版・OSの版・起動回数・画面を開いた回数だけです。入力内容・入力履歴・辞書・設定値・入力欄の文字列は送りません。Windows・macOS・iOS・Android の設定画面・入力メニューからオン／オフの項目を削除しました。Linux・ChromeOS は利用状況を送信しません。
- 設定画面の左側に分類の一覧を追加し、選んだ分類だけを表示できるようにしました。
- **Linux と ChromeOS でも利用状況（Aptabase）を送るようにしました。** Linux は設定画面、ChromeOS は初回の設定画面で同意したあとに送ります。
- **打鍵数と Discord のステータス表示を、Windows・macOS・Linux の PC 版すべてで使えるようにしました。** ChromeOS・Android・iOS は対象外です。
- **ChromeOS 版に、CRX を使わない更新を追加しました。** 設定画面の「ZIPで更新（CRXなし）」で拡張機能のフォルダーを選ぶと、配布 ZIP を SHA-256 で確認して書き込みます。
- **ChromeOS 版の CRX で `CRX_REQUIRED_PROOF_MISSING` と表示される場合の案内を追加しました。** 通常は ZIP を「パッケージ化されていない拡張機能」として読み込んでください。CRX は管理ポリシー（`ExtensionInstallForcelist`）で導入するためのファイルで、手動のドラッグ＆ドロップでは入りません。
- Windows のスタートメニューと Win キーのアプリ一覧に「Meltype-FLASH」を登録するようにしました。Windows 11 の検索から起動できます。
- 設定画面を英語表示できるようにしました。設定の「設定画面の言語」で「自動 / 日本語 / English」を選べます。
- 季節限定の候補（クリスマス・ハロウィン・バレンタイン・お正月）を追加しました。期間外には出しません。
- Space や Tab で変換を始めたときに、最後の文節を選んだ状態から始める設定を追加しました。
- ChromeOS 版は署名済み CRX と `updates.xml` による自動更新に対応しています。ZIP を手動で読み込んだ場合は、設定画面の「更新を確認」から新しい版を確認できます。

## 更新時の注意

- 利用状況の送信は、同意後に停止できません。同意しない場合はアプリを終了してください。
- ChromeOS 版は通常のデスクトップ Chrome 用 IME ではありません。`chrome.input.ime` が使える ChromeOS で利用してください。
- iOS の実機導入には署名が必要です。AI モデルは本体と別ダウンロードです。
