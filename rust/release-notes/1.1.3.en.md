# Meltype-FLASH v1.1.3

This release uses the shared Rust Core on Windows, macOS, Linux, Android, ChromeOS, and iOS. It does not mean that every environment has the same features or the same accuracy.

## What's new

- **Added a first-start consent screen.** It explains the license (GNU GPL v3 or later, no warranty) and how usage data is handled. You cannot start using the settings until you agree.
- **Usage analytics (Aptabase) now also runs on Linux and ChromeOS.** Linux sends from the settings window; ChromeOS sends after agreeing in the first settings screen. It sends only the app version, OS version, launch count, and the number of screens opened. It never sends typed text, input history, dictionaries, settings, or the contents of input fields. After you agree, it cannot be turned off.
- **Added a category list on the left side of the settings window.** Choose General, Input mode, Judgment, Conversion, Candidates, Symbols and spaces, Key operations, Display, Learning, Apps, Logs, or Updates to show only that category.
- **Added an in-app release notes viewer.** It appears once after an update, and can be reopened from the Updates settings, the tray's Updates menu, or the context menu. It renders Markdown and can switch between Japanese and English.
- **Keystroke counts and Discord Rich Presence now work on all desktop builds: Windows, macOS, and Linux.** ChromeOS, Android, and iOS are out of scope.
- **Added a CRX-free update path for ChromeOS.** Choose "Update from ZIP (no CRX)" in the settings, select the extension folder, and the release ZIP is verified with SHA-256 before it is written.
- **Added guidance for `CRX_REQUIRED_PROOF_MISSING` on the ChromeOS build.** Install the ZIP with "Load unpacked" in normal use. The CRX is for managed-policy installation (`ExtensionInstallForcelist`).

## Notes for updating

- After you agree, usage analytics cannot be turned off. If you do not agree, please quit the app.
- Discord presence on macOS and Linux runs only while the settings app `meltype-flash` is running.
- Some Linux/macOS devices and Android/iOS builds are not covered by this release's verification.
- Installing the iOS build on a device requires signing. AI models are downloaded separately from the app.
