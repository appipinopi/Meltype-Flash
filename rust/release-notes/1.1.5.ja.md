# Meltype-FLASH v1.1.5

Windows向けの入力支援を追加した版です。Windows・macOS・Linux・Android・ChromeOS・iOS で共通の Rust Core を使います。

## 今回の変更

- **Windowsの「なう」で、再生中の曲名・アーティストを候補に出すようにしました。** 設定「「なう」で再生中の曲を候補に出す」で切り替えられます（既定ON）。再生中の曲がないときは、これまでどおり時刻を出します。曲名は端末内のファイルだけに置き、外部へ送りません。
- **Meltype IMEで入力モードを切り替えたとき、カーソルの近くに「あ」（日本語）か「A」（英数）を1.2秒表示するようにしました。** 設定「Meltype IME でも入力モードをカーソルの近くに表示」で切り替えられます（既定ON）。フォーカスやクリックは奪いません。
- v1.1.4 の設定画面レイアウト修正、タイムゾーン時刻候補、プレリリース自動更新、打鍵数の既定OFF、Linux/macOS文書も含みます。

## 更新時の注意

- 「なう」の曲取得は、Windowsの設定アプリ（トレイ常駐）が動いている間だけ行います。
- 入力モードの表示は、Meltype IMEのモードを切り替えたときに出ます。表示色の設定は今後の版で対応します。
- 更新前に起動していたアプリは、更新後に一度再起動すると新しいIMEを読み込みます。
