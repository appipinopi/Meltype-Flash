# Meltype-FLASH v1.1.5

This release adds Windows input helpers. It uses the shared Rust Core on Windows, macOS, Linux, Android, ChromeOS, and iOS.

## What's new

- **"なう" now offers the title and artist of the song playing in Windows.** Turn it on or off with "Offer the now-playing song for なう" (on by default). If nothing is playing, the time is shown as before. The song title is kept only in a local file and is not sent anywhere.
- **When the Meltype IME input mode changes, "あ" (Japanese) or "A" (alphanumeric) is shown near the caret for 1.2 seconds.** Turn it on or off with "Show the input mode near the caret in Meltype IME" (on by default). It does not take focus or clicks.
- Includes the v1.1.4 settings layout fix, time-zone clock candidates, pre-release auto-update option, keystroke counting off by default, and the Linux/macOS documentation.

## Notes for updating

- The now-playing title is read only while the Windows settings app is running in the tray.
- The mode indicator appears when the Meltype IME mode changes. Color settings will follow in a later release.
- Apps that were running before an update should be restarted once to load the new IME.
