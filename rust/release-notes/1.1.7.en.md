# Meltype-FLASH v1.1.7

This release fixes the ChromeOS half/full-width key, adds non-blocking conversion, SKK settings, and ReadingLattice accuracy improvements.

## Changes

- **Fixed the ChromeOS half/full-width key.** A changed keyup name/code no longer leaves the key stuck, so the next press returns to Japanese.
- **Added non-blocking conversion.** With “Convert asynchronously” enabled, Space/Convert returns immediately and the candidate view updates when the result arrives. Supported on Windows TSF, IBus and macOS.
- **Added Gamma, Qwen and Shion AI families.** They use the same llama-server/GGUF path as Zenzai. Catalog URLs, SHA-256 and sizes are registered for installation from settings.
- **Added the SKK-like input setting.** Uppercase starts ▽, Space converts with ▼, Enter commits. SKK candidates use the existing candidate window.
- **Improved ReadingLattice accuracy.** Added English contractions, Japanese inflections, number+counter forms (3月, 1人, 10時), email/URL/file/path preservation, domains/version suffixes, acronyms, and user learned English/user dictionary weights.
- **Added a Zenzai GPU setting.** “Zenzai: device” is passed to llama-server as `--device`; empty uses CPU/default GPU.
- Added license notices for `katakana.txt` and `readings-extra.txt`.

## Update notes

- Asynchronous conversion is OFF by default. When enabled, the candidate view may update after a short delay.
- Apps that were running before the update need a restart to load the new IME.
