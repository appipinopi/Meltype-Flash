# macOS 版

macOS 版の導入・設定・困ったときは [mac/README.md](../mac/README.md) を見てください。

- macOS 版は入力メソッド（Input Method Kit）です。Windows 版のような常駐トレイや独立した設定画面はありません。
- 入力メニューから「利用状況を匿名で送る」のオン／オフは v1.1.3 で削除しました。初回起動の同意後に送信し、停止できません。
- 打鍵数は入力メソッドが数え、設定アプリ `meltype-flash` がある場合は Discord ステータスにも表示できます。
- 更新前に起動していたアプリは、更新後に一度再起動すると新しい入力メソッドを読み込みます。
