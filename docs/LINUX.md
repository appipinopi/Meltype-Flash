# Linux 版

Linux 版の導入・設定・更新・困ったときは [linux/README.md](../linux/README.md) を見てください。

- 入力エンジンは IBus / fcitx5 です。
- 設定画面は `meltype-flash` です。インストール形式によってはフルパスで起動します。
- 設定画面には打鍵数・Discord ステータス・利用状況の同意・リリースノートがあります。
- 更新は設定画面の「アップデート」または配布パッケージ（deb / rpm / ZIP）で行います。
- 更新前に起動していたアプリは、更新後に一度再起動すると新しい IME を読み込みます。
