# 上流1.5.0系の照合（2026-11-09）

Meltype-FLASH 1.1.1で、上流 [v1.5.0](https://github.com/yksr-melt/Meltype/releases/tag/v1.5.0)（`36a7c0d9900dff1f41099be027af98bd072ea68a`）の共通Core機能をRustへ移植した記録です。上流と同じ版番号・全機能互換を示すものではありません。

## 今回取り込んだもの

| 対象 | Flashでの対応 |
| --- | --- |
| 最後の文節からの予測（#974） | ライブ変換の最後の文節の読みからも予測候補を出し、選んだときは前の文節を表示のまま残して確定する。`View::predictions` は上流と同じく続きの語だけを並べ、確定・表示は前の文節を足す |
| Tabで選んだ予測を続けて打つと確定（#974） | Tab選択中に文字キーを打つと、その候補を確定してから新しい入力を始める。Escは選択だけを戻す既存動作を維持 |
| 定型句の予測（#1337） | 上流 `greetings.txt` を同梱し、学習がなくても「おはようございます」などを出す。前に確定した語句・ユーザー辞書・選び直しの学習より後ろに置き、`start` の読みまで打ったときだけ出す |
| 版番号を予測・学習に使わない（#1488・#1524） | `Meltype-<数字>`・`Mozc-<数字>`・`Meltype-FLASH <数字>` を予測・学習・候補の先頭から除外。「ばーじょん」には実行中の版を候補として出す |
| 括弧の系統ごとの候補（#1162） | 片括弧・空のペアは、入力した形とその幅違いを先頭に、同じ系統の空ペアだけを並べる。辞書・変換エンジンの候補を混ぜない。`[`・`]`・`z[z]`・全角括弧設定・角括弧設定に対応 |
| Markdownの半角記号（#1560） | `-`・`>`・`*`・`+`・`#`〜`######` のSpace確定を半角の記号+空白にした。3個以上の `-` と2個以上の `*` は入力中から半角で表示し、最初の候補も半角にする |
| 日付の書き方（#1189・#1439） | 「きょう」に8桁の日付（`20261009`）を追加。`10/20` などから出す候補の順を上流に合わせ、年は今日から30日より前なら来年、それ以外は直近の日付を選ぶ。2/29は次のうるう年 |
| 予測のDelete（既存） | Tab選択中のDeleteで、選んだ語句を学習から消す。前の文節を含む予測でも、覚えている語句そのものを消す |

## 移植していないもの

| 対象 | 扱い |
| --- | --- |
| 日英境界判定の作り直し（ReadingLattice、#1185・#1331・#1434・#1437・#1440） | 未移植。Flashは既存の点数付き区切り（`ScoredSegmentation`）を使う |
| かな入力の配列（月・花・NICOLA・中指NICOLA・TRON・SKY、#1428・#1465） | 未移植。親指シフトはキーを離した時点の判定が必要で、Flashの共通Coreはキーアップを受け取らない。各OSの入力層から渡す設計を別途決める |
| 変換の完全非同期化（#1546） | 未移植。FlashのAI変換は別ワーカーと待機期限を使うが、同じ方式ではない |
| Zenzaiの同梱と既定ON（#1427・#1452） | 対象外。Flashはモデルを本体と別に任意導入する方針を維持する |
| Windowsの打鍵数分析（時間帯別・キー別、#952・#1368） | 未移植。Flashの打鍵数は合計・日別までで、分析画面は設定アプリ側の作業になる |
| 「なう」の再生中曲（#1429）、タイムゾーン指定の「とけい」「じこく」（#1451） | 未移植。OSの再生情報・タイムゾーン設定を共通Coreへ渡す境界がない |
| Windows・Mac・Linuxの個別修正（#1494・#1430・#1561・#1602・#1250・#1159・#1497など） | 各OSの実装固有。Rustの別実装のため、そのままの移植対象ではない。同じ不具合がないことの保証でもない |
| 設定画面の分類・プレリリース更新・リリースノート表示（#1338・#1222・#1223） | 未移植。配布・更新のワークフローは今回の依頼範囲外 |
| 辞書の追加語（#1180・#1280・#1294・#1432） | 上流の共有辞書との差分取り込みは別作業。Flash独自の語彙を保つ |

## 検証

- `cargo test -p meltype-core`：共通Coreの単体・統合試験が成功（1.1.1の版番号変更後にも再実行）。新規に `upstream_v150.rs` を追加し、定型句、最後の文節の予測と確定、版番号の除外、括弧の系統、Markdown、日付、予測のDeleteを確認する。
- 既存の上流予測試験（`upstream_prediction_keys.json`）は、Tab選択中に文字を打つ12ケースだけをv1.5.0の確定動作へ更新した。学習が無効なケースなので、保存される語句は変えていない。
- `cargo check --workspace --locked`：Windows上で全クレートのコンパイルを確認。

この記録は共通Coreの移植と自動試験の範囲です。各OSのアプリ・IME・実機入力の確認ではありません。Windows・macOS・Linux・Android・ChromeOS・iOSのビルドと実機確認は、それぞれ別に行います。
