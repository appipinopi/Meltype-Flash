# 報告を受けて追加した設定と候補

Pre6で追加し、Pre7（`0.1.0-pre.7`）にも含まれる変更です。公開状況と配布ビルドの確認範囲は[リリースノート](../rust/RELEASE-NOTES.md)を参照してください。

Rust設定画面の「1. 全般」に以下の4項目を追加しました。いずれも既定はオフです。設定ファイルに項目がない場合もオフとして動作します。

| 設定名 | 操作 |
| --- | --- |
| `DisableZShortcuts` | `z.`、`z/`、`zh`などを記号へ置き換えない。英語判定・句読点設定は通常どおり働きます。 |
| `SpaceAroundNumbers` | 日本語と半角数字の境界に空白を入れる。`この処理を3回実行します` → `この処理を 3 回実行します`。英数字の識別子・URL・ファイル名と既存の空白は維持します。 |
| `MuhenkanKatakanaCycle` | 入力中の無変換で全角カタカナ→半角カタカナ→ひらがなを切り替える。「キーの役割を分ける」より優先します。 |
| `NumpadDirect` | テンキーの数字と `* + - . /` を直接確定する。入力中の文字列は先に一度確定します。Windowsの仮想キーを対象とし、Linux等でテンキーを区別する接続は未対応です。 |

入力中の **Ctrl+Enter** で確定できます。Windows TSFでこのキーがコアに届く前に確定・通過する経路を修正しました。入力がないときはアプリへ渡るため、投稿の可能性があります。自由なキー割り当ての全OS接続までは確認していません。

変換中の **Page Up／Down** は9候補ずつページを移動し、端まで進むと循環します。入力を確定せず、アプリへキーも渡しません。単一ページと最終ページが少数のケースを検査しています。Tabで格子状に展開する機能は未対応です。共通コア・隔離IBusの検査と、実際の報告アプリでの確認は区別しています。

日付は `10/20`、`10月20日`、`10がつ20にち` の候補に `10月20日`、`10/20(火)`、`10月20日(火)`、`2026/10/20(火)` などを出します。曜日は現在の年で計算します。「きょう」にも曜日付きスラッシュ形式を追加しました。候補生成のテストを確認済みです。保護された数値をホスト側の変換エンジンがどう扱うかを含め、各OSの画面上での選択は未確認です。

「めるたいぷ」は `Meltype-flash` と `Meltype`、「ばーじょん」は実際にビルドしたRustパッケージのバージョンを含む候補を追加しました。

## config.jsonの補完用Schema

Rust CLIの管理操作から、設定ディレクトリの `config.schema.json` を生成し、現在の `config.json` に `"$schema": "./config.schema.json"` を保存できます。実行前の設定値を保ち、他プロセスの設定変更と同じロックを使います。

```powershell
meltype-rs --control '{"op":"settings_schema_export"}'
```

`{"op":"settings_schema"}` は書き込みを行わずSchemaのJSONを返します。Schemaは既定値・既存のUIメタデータ・追加設定から生成します。項目の型、列挙値、説明、未知の最上位項目を検査でき、設定ファイルの保存で `$schema` を保持します。プロファイル等の配列内の詳細構造の検証、自動起動時の再生成、各OSの設定画面からの書き出し操作は未対応です。アプリ更新後は同じコマンドで再生成してください。未知の設定を実行時に削除することはありません。
